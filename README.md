# 🏥 Healthcare Analytics Dashboard | Power BI

## 📌 Project Overview

The Healthcare Analytics Dashboard is a data analytics project developed using Microsoft Power BI. It aims to present healthcare data through interactive visualizations and help users explore admission trends, hospital activity, patient demographics, and billing patterns.

## 🎯 Objectives

* Analyse healthcare admission patterns.
* Explore hospital-wise activity.
* Understand patient demographic trends.
* Analyse billing amounts across different categories.
* Present key metrics through interactive dashboards.

## 🛠️ Tools and Technologies

* Microsoft Power BI
* Power Query
* DAX (Data Analysis Expressions)
* Data Visualization
* Data Cleaning and Transformation

## 📊 Dashboard Pages

### 1. Healthcare Overview

Provides an overview of important healthcare metrics and admission trends.

### 2. Hospital Analysis

Explores hospital-wise admissions and healthcare activity.

### 3. Financial Analysis

Presents billing patterns and comparisons across available categories.

### 4. Patient Analysis

Explores patient demographics and admission-related patterns.
